Интегрированный сервис для работы с документами

Интегрированный сервис, позволяющий создавать типовые документы с минимальным количеством ошибок. Включает панель администратора и клиентскую часть.

B2CWeb

Задача и итог

Проблема

Пользователи экосистемы предпринимательских сервисов сталкивались с неудобством: при необходимости заполнить и отправить документ им приходилось обращаться к сторонним решениям, что нарушало непрерывность их взаимодействия с продуктом.

Задача

Создать отдельный модуль, который можно будет интегрировать в различные сервисы компании, чтобы пользователи могли заполнять типовые документы, не прерывая свой путь.

Моя роль

Была единственным дизайнером на проекте. Работала с менеджером, тестировщиком и двумя разработчиками. Проводила тестирование прототипов.

Результаты

  • Спроектировала MVP-версию сервиса, который позволяет администраторам создавать шаблоны документов, а пользователям их быстро заполнять.

* Поскольку проект был приостановлен, нет возможности собрать метрики для оценки эффективности сервиса.

Анализ конкурентов

Поскольку сервис создавался с нуля, перед тем как приступить к проектированию сервиса для работы с документами, я проанализировала текущие решения на рынке и выделила наиболее подходящие, которые легли в основу нового дизайна сервиса.

Разработка концепций

Было разработано четыре концепции главной страницы сервиса, предназначенной для ключевых пользовательских взаимодействий.

Необходимо было сделать страницу максимально удобной для юристов, которые создают шаблоны документов. Основная цель — чтобы настройка сторон договора и его блоков была нативно понятной. Для этого рабочая область была разделена на три зоны: слева размещены ключевые действия со сторонами, справа — детальная настройка выбранной стороны.

Прототипирование

Чтобы протестировать удобство и функциональность интерфейса, мы вместе с менеджером пригласили юриста, который в дальнейшем будет создавать шаблоны документов. Он оставил ряд комментариев, по которым впоследствии были внесены доработки.

Передача в разработку

После финального согласования макетов я подготовила их к передаче в разработку.

Клиентская часть

Первая итерация

Для первой итерации был собран быстрый прототип, который выявил основные проблемы интерфейса на основе обратной связи:

  • Очень много свободного пространства справа.
  • Не интуитивно понятно, куда кликать, когда постепенно заполняешь поля (для этого предложили использовать кнопку «Далее»).
  • Не очевидно, что нужно переключаться между табами, чтобы продолжить заполнять.

После этого мы перешли ко второй итерации, чтобы улучшить юзабилити и логику взаимодействия.

Вторая итерация

Во второй итерации были учтены замечания первой версии. Интерфейс стал более интуитивным: я устранила лишние пустые пространства, сделала переключение между сторонами и их заполнение более понятным, а также добавила уведомление для улучшения взаимодействия пользователя с сервисом.

Также была доработана мобильная версия.
